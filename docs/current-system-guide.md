## 0. 一页总览

### 0.1 系统定位

TSConstructor2 是一个“**示例驱动的单变量时序类别构造**”Demo：

- 左副列：选目标类别、找参考素材、看结构分布、浏览样本。
- 右主列：把手工编辑与参数化方法写成**配方**，再按泛化声明批量生成候选。
- 顶栏：数据集/会话边界、计数、撤销、导出、记录与帮助。

### 0.2 两列与主列槽位

```text
Dock（顶栏）
├─ 左副列（窄）                     ├─ 右主列（宽，本文重点）
│  ├─ 阶段条                        │  ├─ 工作模板条
│  ├─ 目标类别                      │  ├─ 编辑画布（含左下角素材源角窗）
│  ├─ 类分布条                      │  ├─ 方法面板 + 配方面板
│  ├─ 结构面                        │  ├─ 泛化控制
│  ├─ 参考素材架                    │  └─ 生成条
│  └─ 样本列表                      │
└─ 记录 / 帮助抽屉
```

### 0.3 主列五块功能

| 主列区域 | 作用 | 主要产出 |
|---|---|---|
| 工作模板条 | 显示当前基源、配方摘要、目标 | 当前工作上下文 |
| 编辑画布 | 选区、点拖拽、查看层叠结果、克隆落点、P1 结构叠加 | 选区、`deform` 步、视觉反馈、结构选择 |
| 方法面板 | 组件 / 编辑 / 素材三类方法入口 | 新的配方步骤 |
| 配方面板 | 排序、启停、参数、源、落点、`vary` | 可执行、可复用的配方 |
| 泛化控制 + 生成条 | 声明可变维度、批量实例化、导出 | 候选集、批次、导出 JSON |

### 0.4 核心对象

- **基源（base）**：当前工作模板的承载样本；主列只有一个主基源（第一条 `base` 素材）。
- **选区（region）**：数量不限、至少 3 点；是组件作用区间、区间编辑作用域、克隆落点来源。
- **配方（steps）**：有序操作步列表；执行序 = 列表序。
- **候选（candidate）**：按配方 + 泛化轴实例化、执行后得到的曲线。
- **批次（batch）**：一次“生成候选”的产物；本会话所有批次保存在 `store.batches`，供“导出全部批次”。

### 0.5 三条系统契约

1. **目标类别 = 任务 scope**：显式声明；切换目标 = 重建容器。
2. **投影基底按会话冻结**：PCA / t-SNE / UMAP 切换时重算，会话内不隐式重算。
3. **读数走登记口径**：粗糙度、尾部电平差、几何结构计数等；不做自动择优。

## 1. 顶栏与左副列（简）

### 1.1 顶栏 Dock

- **数据集菜单**：点击当前数据集名切换；切换会结束当前会话，弹出确认，并保留生成 `seed` / `count`（通过 URL 参数）。
- **目标 / 素材 / 配料 / 候选计数**：候选计数显示本会话所有批次累计数。
- **撤销**：撤销最近一次进入撤销栈的配方/选区操作，也可用 `Ctrl+Z`。
- **导出候选**：导出**最新批次**候选（含配方、差异签名）。
- **导出配方**：导出当前配方与素材清册。
- **导入配方**：选择配方 JSON，替换当前配方（先确认）；基源不进入配方，克隆/纹理源按「片段/纹理角色 + 序号」重绑到当前素材；当前没有对应素材时保留原样本 ID，跨数据集缺源则停用该步并提示。
- **记录 / 帮助**：打开右侧抽屉。

### 1.2 左副列（第一阶段）

- **目标类别**：新建类别 / 缺类重建。确定后清空素材、配方、候选/批次、选区（记录保留）。
- **类分布条**：显示可用类计数；点击类可过滤样本列表；缺类重建时隐藏类只显示计数。
- **结构面**：PCA / t-SNE / UMAP 投影；点击选中、拖拽/框选批量勾选、Shift 拖平移、滚轮缩放、双击重拟合；显示素材架与工作模板投影点。
- **参考素材架**：角色可叠加为 **基源 / 片段 / 纹理**；片段角色有可拖拽区间；克隆只取片段列表，纹理只取纹理列表。
- **样本列表**：勾选样本后成批加入基源/片段/纹理；可按粗糙度、尾部差排序；点击行展开样本仪。
- **阶段条**：②「候选审查与检查」现提供**临时最简候选查看器**（查看本会话所有批次候选、点选波形、查看差异签名）；其余 RQ3 检查/裁决仍为占位。

#### 1.2.1 临时候选查看器（阶段②）

**进入**：点阶段条「② 候选审查与检查」。

**操作**：

1. 用「批次」下拉选择 `全部` 或某一批；下拉显示每批候选数。
2. 候选列表每行显示：迷你波形、候选 ID、批次号、基源类别、差异签名数量。
3. 点击任意行 → 下方详情显示：
   - 候选 ID、批次、seed、基源/基源类、目标标签；
   - 基源（灰）与候选（橙）的波形对照；
   - 该候选的差异签名 chips。
4. 选中状态同步到 `store.selectedCandidateId`。

**边界**：只读查看；没有质量评分、覆盖、裁决、归档或其他 RQ3 功能。

## 2. 主列详解

### 2.1 工作模板条

**位置**：主列最上方。

**显示内容**：

- 当前主基源 ID 与类别；
- 当前配方步骤名称序列；
- 目标类别名称；
- 若没有基源，显示“未指定基源”和“去副列取材”按钮。

**操作**：

1. 在左副列样本列表勾选样本。
2. 点「＋基源」加入素材架；第一条基源成为主基源。
3. 回到主列，工作模板条显示基源与配方摘要。
4. 若未指定基源，画布显示提示，不能编辑。

---

### 2.2 编辑画布

**位置**：主列第二块，占据主要高度。

#### 2.2.1 工具条

顶部只有两个直接工具和一个笔宽：

| 控件 | 作用 | 操作 |
|---|---|---|
| **选区** | 划定/重选区间 | 在画布上按住拖拽；从右往左也可以 |
| **点拖拽** | 局部手动改值 | 在波形上按住并上下拖 |
| **笔宽（点）** | 点拖拽的横向高斯宽度 | 数字输入，2–30，默认 8 |

说明：

- 顶部不再有「时间形变 / 区间擦除」按钮；它们从方法面板的「编辑」类加入。
- 笔宽单位是**采样点**，不是像素；只作用于点拖拽。
- 点拖拽的纵向位移单位是**原始值**，不是 ×σ。

#### 2.2.2 选区

**操作**：

1. 选「选区」工具。
2. 在画布上拖拽出一段。
3. 顶部右侧出现 `R# 起–止` 芯片；点击芯片选中，点 `✕` 删除。
4. 选区数量不限；每个选区至少 3 点。

**用途**：

- 组件的作用区间；
- 时间形变、区间擦除、平移、缩放的执行区间；
- 克隆的落点（当前选区）。

#### 2.2.3 点拖拽

**操作**：

1. 选「点拖拽」。
2. 在波形上按住并上下拖动。
3. 拖动过程中出现虚线预览。
4. 松手后写入一条 `deform` 步；无位移时不写步。

**语义**：

- 锚点 = 按下点；
- 笔宽 = 高斯 σ；
- `out[i] = cur[i] + amp · exp(−½((i−anchor)/width)²)`；
- `amp` 是原始值位移，无裁剪；
- 可在配方面板继续改锚点、宽度、强度。

#### 2.2.4 图层、读数与克隆落点

- **基源**：灰线。
- **中间结果**：橙色，逐级渐淡。
- **最终结果**：橙色粗线。
- **拖拽预览**：虚线。
- **失败步骤**：灰色虚线，并在 title 中显示原因。
- **悬停**：显示 `t=… · 基源 … → 模板 …` 读数。
- **克隆落点**：存在克隆步时，画布显示蓝色落点带与落点起线；长度为克隆源段长度。
- **纵向自适应**：画布按当前所有阶段自动取纵轴范围。
- **横向**：当前没有横向缩放；这是已知限制。

#### 2.2.5 左下角素材源角窗

画布左下角会为「克隆 / 纹理」显示一个 v4 风格的小窗：

- 有克隆/纹理步骤时出现；
- 优先跟随当前选中的克隆/纹理步；若当前选中其他步骤，则显示第一条相关步骤；
- 标题：`克隆源 A` 或 `纹理源`；
- 下拉：只列出当前副列的 **片段列表** 或 **纹理列表**；
- 小波形：显示源样本；
- 克隆：在小波形上拖拽刷选源段；显示 `落点 …` 与「落点 = 选区」按钮；
- 纹理：整条纹理，不刷选源段；强度/趋势窗在配方面板调整。

#### 2.2.6 P1 结构识别叠加

**入口**：编辑画布工具条最右侧的「结构」按钮；没有基源时禁用。

**显示与筛选**：

- 结构叠加只检测当前**主基源原始波形**，不检测编辑后的最终模板；
- 默认显示：平台 / 峰 / 谷 / 斜坡四类；
- 点击类型标签可显示/隐藏该类型；
- 「灵敏度」下拉：严格 / 标准 / 灵敏（映射到检测器阈值的集中预设）；
- 画布下方显示结构列表与当前选中结构的摘要。

**画布标记**：

- 平台、斜坡：区间矩形 + 类型字母；
- 峰、谷：实际索引处的竖线 + 点标记；
- 选中结构加粗/高亮；
- 点击画布标记与点击结构列表项都会选中同一结构，并写入 `store.structureView.selectedId`；
- 标记层为低透明度，不遮挡基源/模板波形。

**结构实例字段**（适配层输出）：

- `type`：`plateau / peak / valley / ramp`；
- `startIndex / endIndex / centerIndex`；
- `relativePosition / width / normalizedWidth`；
- `level / relativeLevel / height / prominence`（σ 口径）；
- `direction`（斜坡）、`properties`（类型特有原始属性）；
- 稳定但不跨样本的 `id`。

**当前边界**：

- 这是 P1 的“识别与选择”，尚未实现 P2 的结构锚定；
- 结构选择结果暂未写入配方 `target`，也不能跨基源迁移；
- 不提供结构自动编辑、质量评分或裁决。

### 2.3 方法面板

**位置**：主列下半部左侧，与配方面板并排。

**总入口**：点击方法条目即加入配方；失败/缺少前置条件时用 toast 明确提示。

#### 2.3.1 组件（5 个）

| 组件 | 类型 | 默认参数 | 主要参数 | 作用 |
|---|---|---|---|---|
| 脉冲 | 区间中心峰 | width 7, amp 0.9 | 宽度/强度 | 区间中心的高斯核峰 |
| 平台 | 区间电平 | width 26, amp −0.4 | 长度/强度 | 区间内的平滑抬升或压平段 |
| 趋势 | 区间倾斜 | amp 0.4 | 强度 | 区间内线性倾斜 |
| 震荡 | 区间纹理 | width 34, period 7, amp 0.14 | 包络宽/周期/强度 | 区间内包络加权正弦 |
| 噪声 | 区间扰动 | amp 0.05, win 1 | 强度/平滑窗 | 区间内种子化均匀抖动 |

**加入行为**：

- 组件不再使用 `anchor`；每个组件都必须有 **`span` 作用区间**；
- 有点击时选中的选区：`span = 当前选区`；
- 无选区：`span = [0, L-1]`（整条）；
- 区间外形状为 0；区间内由组件的宽度/周期等形状参数决定；
- 所有组件默认 `mix = add`、`weight = 1`；界面不暴露 multiply/replace；
- `位 / 宽` 泛化现在统一作用于区间：位 = 区间整体平移，宽 = 区间长度变化；
- 参数范围按当前数据集收窄；
- 配方面板的作用域直接显示选区名（如 `R1` / `R2`）；无选区、覆盖整条时显示「整条」。

**组件形状语义**（`σ = 基源原始标准差`）：

- 默认 `cur[i] += stdBase · amp · shape[i]`；
- 所有组件先计算形状，再按 `span` 截断：区间外为 0；
- 脉冲：`exp(−½z²)`；
- 平台：两侧 `tanh` 平滑边缘；
- 震荡：`sin(2π(i−a)/period) · exp(−½z²)`；
- 趋势：区间内从 −1 到 +1 的线性斜坡；
- 噪声：区间内种子化均匀值（可选滑动平均）。

#### 2.3.2 编辑（4 个区间操作）

所有编辑方法都要求当前有选区；没有选区会提示先划选区。配方 item 的区间显示选区名（如 `R1`）。

| 方法 | 默认 | 参数 | 作用 |
|---|---|---|---|
| 时间形变 | `factor=1.1`, `delta=0` | 伸缩 0.8–1.25；位移 −12..12 点 | 区间内时间重映射 + 重采样 |
| 区间擦除 | 无额外参数 | 无 | 用区间两端点做余弦平滑桥接 |
| 平移 | `delta=4`, `feather=0` | 位移 ±(区间长度−1) 点；羽化 0–20 | 选区波形整体左右平移 |
| 缩放 | `factor=1.2`, `feather=8` | 倍率 0.5–2；羽化 0–20 | 按区间局部均值缩放幅值 |

**时间形变**：

- 区间内按 `factor` 伸缩，`delta` 移动段起点；
- 两侧线性补偿回端点；首尾钉住；8% 区间长度余弦平滑；
- 区间过短或越界时该步失败，不静默。

**区间擦除**：

- 始终保持区间左、右端点原值；
- 内部用余弦平滑曲线连接两端点，不再保留原区间形状；
- 不再提供 `interp / zero` 方式，也不再使用羽化参数。

**平移**：

- 以选区内波形为源，按 `delta` 点整体搬到左/右位置；
- 正值向右、负值向左；
- 源区间用左右外侧值做平滑桥接，落点写入原波形；
- `羽化 = 0` 是完全刚体平移，两个边界一起移动；
- 羽化 > 0 只在落点两端与周围曲线混合，避免硬接缝；
- 区间长度不变；落点超出数据范围的部分裁剪。

**缩放**：

- `pivot` = 选区内当前值的局部均值；
- `out[i] = cur[i] + (factor−1)·(cur[i]−pivot)·w[i]`；
- 两端余弦羽化回原值；
- 不改变时间位置/区间长度。

#### 2.3.3 素材（克隆 / 纹理）

| 方法 | 源限制 | 默认 | 作用 |
|---|---|---|---|
| 克隆 | 副列「片段」列表 | 第一条片段 + 其片段区间；落点优先当前选区 | 把源段搬到目标落点；可改源段、落点、混合、接缝 |
| 纹理 | 副列「纹理」列表 | 第一条纹理；`amount=0.2`, `win=9` | 借源样本高频残差，按 σ 注入全条 |

**克隆**：

- 点击后立即生成一个克隆步；
- 源段来自片段的 `seg` 区间，可在左下角小窗拖拽重选；
- 落点：有选区则使用当前选区；否则使用默认落点（长度中点起）；
- 可在配方面板或左下角小窗改源、改落点；
- 克隆步内部仍是 `transplant` 引擎。

**纹理**：

- 点击后立即生成一个纹理步；
- 源只能从纹理列表选；
- 整条残差注入，不选源段；
- 强度与趋势窗在配方面板修改。

**源限制**：

- 克隆不会回退到基源或其他角色；
- 纹理不会回退到片段；
- 对应列表为空时点击方法会 toast 提示。

### 2.4 配方面板

**位置**：主列下半部右侧，与方法面板并排。

#### 2.4.1 配方行

每行显示：

- 执行序号；
- 步骤名称（如 脉冲 / 时间形变 / 克隆 / 纹理 / 点拖拽）；
- 作用域（锚点、区间、落点、全条等）；
- 源提示（克隆源、纹理源等）和擦除/平移结果摘要。

#### 2.4.2 行操作

| 控件 | 作用 |
|---|---|
| 点击行 | 选中步骤 |
| `● / ○` | 启用 / 停用（停用保留在配方中） |
| `↑ / ↓` | 调整执行顺序 |
| `⧉` | 复制该步 |
| `✕` | 移出该步 |
| 顶部「清空」 | 清空全部步骤 |

#### 2.4.3 源与落点

- **克隆**：「克隆源」下拉只列出片段；显示落点，提供「落点 = 当前选区」。
- **纹理**：「纹理源」下拉只列出纹理。
- **区间擦除**：固定为两端点平滑连接，不再显示方式下拉。

#### 2.4.4 参数滑条

按步骤类型自动生成：

| 步骤 | 参数 |
|---|---|
| 组件 | 按组件登记表生成（锚点/宽度/周期/强度等） |
| 点拖拽 | 锚点 / 宽度 / 强度 |
| 时间形变 | 伸缩 / 位移 |
| 区间擦除 | 无额外参数 |
| 平移 | 位移 / 羽化 |
| 缩放 | 缩放倍率 / 羽化 |
| 克隆 | 混合 alpha / 接缝 seam + 源/落点 |
| 纹理 | 强度 / 趋势窗 |

参数滑条修改会立即影响工作模板重算。

#### 2.4.5 可变化维度（vary）

每步底部显示「生成时可变」芯片；只显示对该步骤有效的维度：

- `位`：锚点/区间位置漂移；
- `宽`：宽度、周期、时间伸缩、落点长度；
- `强`：强度、alpha、缩放倍率、纹理 amount；
- `源`：克隆源 / 纹理源替换。

规则（组件现在全部有 `span`）：

- 组件：显示「位 / 宽 / 强」；位 = 区间平移，宽 = 区间长度；
- `texture` 只显示「强 / 源」；
- `erase` 只显示「位」；
- `shift` 只显示「位」；位 = 区间整体平移；
- `scale` 显示「位 / 强」；
- `warp` 显示「位 / 宽」；
- `transplant` 显示「位 / 宽 / 强 / 源」。

#### 2.4.6 执行语义

- 执行序 = 列表序；停用步骤跳过。
- 某一步失败时：保留前值，记录失败原因，继续执行后续步骤。
- 生成时不会做“机械拒绝择优”；能算就产出。
- 撤销栈覆盖配方步骤和选区快照；素材架、目标、候选、勾选不在撤销栈。

### 2.5 泛化控制

**位置**：配方面板下方。

| 轴 | UI | 默认/范围 | 作用 |
|---|---|---|---|
| 基源替换 | 复选框 | 开；需要 ≥2 个基源 | 每条候选从基源池换承载样本 |
| 片段 / 纹理源替换 | 复选框 | 开；需要 ≥2 个供体 | 克隆换片段源，纹理换纹理源 |
| 参数扰动 | 滑条 | 0–50%，默认 20% | 强度/alpha/缩放倍率/amount 百分比抖动 |
| 区间平移 | 滑条 | 0–12 点，默认 4 | 组件 span、warp δ、其他区间整体平移 |
| 区间长度 | 滑条 | 0–50%，默认 15% | 组件 span 长度、warp factor、克隆落点长度 |
| 残差注入 | 滑条 | 0–0.3σ，默认 0.10 | 生成后额外注入随机供体残差 |

说明：

- 这里声明的只是“允许变化”；每条候选实际是否变化由 seed 与实际参数决定。
- 下方会回显“上一批实际”的各轴触发次数。
- 全部锁定时候选可能逐位相同；seed 只保证可复现，不保证多样性。
- `source` 轴换的是整条配方的基源，不是单步源。
- 各步骤的无效维度已在配方 `vary` 中隐藏。

### 2.6 生成条

**位置**：主列最下方。

#### 2.6.1 生成

- **数量**：1–100，默认 24。
- **seed**：默认 42；同 seed + 同设置 = 可复现。
- **生成候选 ×N**：按当前配方与泛化轴生成一批候选。

生成门槛：

1. 已载入数据集；
2. 至少一个基源；
3. 配方至少一步；
4. 至少一步启用。

#### 2.6.2 批次与计数

- 生成后显示：批次编号、本批产出/请求数量、seed；
- 右侧显示：本会话累计候选数与批次数；
- `store.candidates` = 最新批次；`store.batches` = 本会话所有批次。

#### 2.6.3 导出全部批次

按钮位于「生成候选」右侧：

- 把所有批次候选合并为一个 JSON；
- 每个候选包含 `values`、`steps`、`tags`、`seed`、`noiseSeed`、`baseId`、`baseClass`、`label`；
- 供 1NN 脚本直接作为训练集，详见第 4.4 节。

#### 2.6.4 候选展示边界

主列生成条本身**不展示候选波形**；生成后主要得到计数、批次信息和导出文件。  
阶段②左副列现已提供**临时最简候选查看器**：可查看本会话所有批次的候选、点选行查看候选波形与基源对照、查看差异签名；它只做查看，不做质量评分、覆盖、裁决或归档。

## 3. 执行与数据结构

### 3.1 配方步骤类型

| 类型 | 来源 | 作用域 | 主要参数 |
|---|---|---|---|
| `component` | 组件 | 区间 | span, width, period, amp, win |
| `deform` | 画布点拖拽 | 点邻域 | anchor, width, amp |
| `warp` | 编辑·时间形变 | 区间 | span, factor, delta |
| `erase` | 编辑·区间擦除 | 区间 | span |
| `shift` | 编辑·平移 | 区间 | span, delta, feather |
| `scale` | 编辑·缩放 | 区间 | span, factor, feather |
| `transplant` | 素材·克隆 | 跨样本区间 | source, srcSpan, dstSpan/dstStart, alpha, seam |
| `texture` | 素材·纹理 | 全条 | source, amount, win |

### 3.2 执行公式摘要

- **组件**：`cur + stdBase · amp · shape`，`shape` 只在组件 `span` 内非零（UI 只使用 add，`weight=1`）。
- **点拖拽**：`cur + amp · gauss(i; anchor, width)`。
- **时间形变**：区间内时间映射 + 线性端点补偿 + 重采样。
- **区间擦除**：保留区间两端点，内部用余弦平滑桥接。
- **平移**：源区间整体搬移 `delta` 点，源区平滑填桥，落点可选羽化。
- **缩放**：`cur + (factor−1)(cur−pivot)w`，`pivot` = 区间局部均值。
- **克隆**：截取源段；落点长度不同则重采样；按 `alpha` 混合；两端 cosine seam。
- **纹理**：`residual = donor − MA(donor, win)`；按 RMS 归一化；`cur + stdBase · amount · residual`。

### 3.3 候选差异签名

每条候选带 `tags`，记录实际触发的变化，例如：

- `源换`
- `位+3`
- `宽−12%`
- `强+8%`
- `周+5%`
- `δ+2`
- `f+4%`
- `残差注入 0.17σ`

`lastBatch.axisCounts` 汇总上一批各轴的触发次数。

### 3.4 确定性与失败

- 所有随机源来自种子链；同一 seed + 设置可复现。
- 参数不合法、区间过短、源缺失等会让该步失败；失败步保留前值并记录原因，不静默跳过。
- 没有机械拒绝/自动择优；质量评估、裁决等属于第二阶段，目前只有临时候选查看器。

## 4. 典型操作流程

### 4.1 从零构造一个工作模板

1. 左副列：设定目标类别（新建 / 缺类重建）。
2. 样本列表勾选样本 → 「＋基源」加入素材架；第一条基源成为主基源。
3. 在主列画布用「选区」划一段（可选）。
4. 在方法面板点组件 / 编辑 / 素材方法加入配方。
5. 在配方面板调参数、源、落点、`vary`。
6. 在泛化控制声明可变维度。
7. 生成候选；用「导出全部批次」导出。

### 4.2 克隆操作

1. 左副列样本列表选一个样本 → 「＋片段」。
2. 方法面板 → 素材 → **克隆**。
3. 画布左下角出现「克隆源 A」：
   - 下拉换片段源；
   - 在小波形上拖拽刷选源段；
   - 若有选区，落点自动使用当前选区；也可点「落点 = 选区」重新指定。
4. 配方面板调整 alpha / seam，或改落点。
5. 画布上的蓝色落点带随源段长度/落点更新。

### 4.3 纹理操作

1. 左副列样本列表选一个样本 → 「＋纹理」。
2. 方法面板 → 素材 → **纹理**。
3. 左下角「纹理源」下拉只列出纹理列表；小波形显示源样本。
4. 配方面板调整 **强度** 与 **趋势窗**。
5. 纹理是整条注入，不做源段刷选；`vary` 可开「强 / 源」。

### 4.4 生成、导出与 1NN 测试

1. 生成条设数量/seed，点「生成候选」。
2. 可重复生成多批；候选计数累计，`store.batches` 保留所有批次。
3. 点「导出全部批次」得到 `tsc2-candidates-all-*.json`。
4. 默认模式一次输出两份结果：

   ```bash
   npm run test:wafer
   ```

   - **结果 A（全量）**：训练集 = `Wafer_TRAIN` 全量 1000 条；
   - **结果 B（仅正常类）**：训练集 = `Wafer_TRAIN` 中 label `1.0000000e+00` 的 903 条；
   - 两份结果都用 `Wafer_TEST` 全量 6164 条测试；
   - 1NN 使用原始值欧氏距离，不做归一化、不重采样。

5. 自定义稀有类增强模式（单份结果，行为不变）：

   ```bash
   npm run test:wafer:custom
   ```

   等价于：

   ```bash
   npm run test:wafer -- --train scripts/wafer_test/tsc2-candidates-all-task-20261021-165736.json
   ```

   - 训练集 = 原始 `Wafer_TRAIN` 中所有**非稀有类**样本 + 导出 JSON 中全部候选；
   - 导出 JSON 的全部候选默认标为稀有类 `-1.0000000e+00`；
   - 原始 `Wafer_TRAIN` 中的稀有类不参与训练（稀有类彻底重建）；
   - 测试集仍为 `Wafer_TEST` 全量 6164 条。

   可选参数：

   ```bash
   --train-data <file>   原始训练集
   --test-data <file>    原生测试集
   --rare-label <label>  自定义模式候选标成的稀有类（默认 -1.0000000e+00）
   --normal-label <label> 默认模式“仅正常类”筛选标签（默认 1.0000000e+00）
   --json                输出机器可读 JSON（供 suite 使用）
   ```

6. 临时一键汇总：默认两份结果 + 遍历 `scripts/wafer_test/*.json` 的多份自定义结果：

   ```bash
   npm run test:wafer:suite
   ```

   最后统一输出一张 Markdown 表格。

7. P1 结构适配层单测：

   ```bash
   npm run test:structures
   ```

## 5. 当前边界与已知限制

1. **第二阶段只做了临时查看器**：候选结果查看已可用；质量维度、裁决、判据板、归档等其余 RQ3 仍为占位。
2. **候选只读查看**：阶段②可看候选波形与差异签名，但没有质量评分、比较、裁决或多选操作。
3. **无持久化 / 无导入**：刷新即失；导出 JSON 是唯一出口。
4. **撤销范围有限**：配方步骤 + 选区；素材架、目标、候选、勾选不在撤销栈。
5. **无横向缩放**：画布只能自适应纵向，152 点局部微调精度有限。
6. **区间编辑没有画布拖拽**：warp / erase / shift / scale 只能从方法面板加入后在配方面板调参。
7. **素材源要求严格**：克隆只认片段列表，纹理只认纹理列表；列表为空时不会回退。
8. **纹理全条**：纹理不做源段选择；克隆才有源段刷选。
9. **P1 已接入、P2 未接入**：结构可识别、筛选、选中，但还不能作为配方 `target` 跨基源迁移；这是下一阶段工作。
10. **自定义 1NN 的稀有类标签**：自定义 JSON 全部候选按默认 `-1.0000000e+00` 处理；如果 JSON 实际来源不同，用 `--rare-label` 显式指定。
11. **自定义模式的性能不代表最终质量**：示例 JSON 只是流程样例，训练集只有 8 条增强稀有类，结果只用于确认流程可运行。
